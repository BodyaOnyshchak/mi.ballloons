# MI ballloons — інтернет-магазин кульок

Чернетка сайту для [@mi.ballloons](https://www.instagram.com/mi.ballloons/) — кульки, фотозони та декор у Києві.
Версія для погодження з клієнтом: дизайн, структура й логіка вже працюють, контакти, ціни та фото потрібно уточнити.

## Що є на сайті

| Сторінка | Файл | Що там |
| --- | --- | --- |
| Головна | `index.html` | Живе демо: відвідувач пише текст — він одразу зʼявляється на баблі; хіти, свята, конструктор, фотозони, доставка, питання |
| Каталог | `catalog.html` | 19 готових композицій, фільтри за категорією та святом, сортування |
| Товар | `product.html?id=…` | Превʼю оновлюється, коли змінюєте напис, цифри чи колір; склад композиції; заявка на фотозону |
| Конструктор | `constructor.html` | Кульки 10 видів і 42 кольори, написи 4 шрифтами, перетягування, коробка-сюрприз, стрічки, ціна в реальному часі, посилання на композицію, опис для Direct |
| Оформлення | `checkout.html` | Контакти, доставка чи самовивіз, дата й час, оплата на рахунок ФОП, текст замовлення для Direct |
| 404 | `404.html` | Сторінка «не знайдено» |

Кошик працює на всіх сторінках і зберігається в браузері.

## Фірмовий стиль

- Кольори з логотипа й стрічки Instagram: пудрово-рожевий `#F4C2D0`, фон «зефір» `#FFF6F8`, текст «чорнило» `#2A1D24`, шампань `#E9D6B6`, вечірній фон для фотозон `#241A21`.
- Шрифти: **Unbounded** (заголовки — округлі, як надуті літери MI), **Bad Script** (рукописні примітки, як «ballloons» у логотипі), **Onest** (текст).
- Картки товарів мають форму арки — як круглі стійки фотозон.
- Логотип перемальований у SVG (`MB.logo()` у `assets/js/core.js`). Якщо є оригінал у векторі — краще замінити.

## Ілюстрації замість фото

Усі товари зараз намальовані тим самим рушієм, що й конструктор (`assets/js/art.js`), тому каталог виглядає цілісно ще до фотосесії.
Щоб поставити справжнє фото, додайте товару поле `image`:

```js
{ id: 'nizhnist', name: 'Ніжність', image: 'assets/img/products/nizhnist.webp', … }
```

Рекомендований формат фото — 800×1000 px (4:5), WebP.

## Де що змінювати

Майже все редагується в одному файлі — `assets/js/data.js`:

- `MB.config` — телефон, Telegram, Viber, адреса магазину, графік, вартість доставки, поріг безкоштовної доставки.
- `MB.palette` — кольори кульок (назва, колір, тип покриття).
- `MB.types` — види кульок і ціни за штуку.
- `MB.extras` — доплати: напис, міні-кульки в баблі, Hi-Float, коробка, напис на коробці, грузик-кубик.
- `MB.products` — товари каталогу: назва, ціна, опис, склад (`art`), що можна змінити (`options`).
- `MB.templates` — шаблони, з яких стартує конструктор.
- `MB.faq` — питання та відповіді.

Кольори й шрифти сайту — на початку `assets/css/main.css` (блок `:root`).

## Що треба уточнити в клієнта

Усе позначено в `data.js` коментарем `ЗАМІНИТИ`.

- [ ] Номер телефону, посилання на Telegram і Viber
- [ ] Точна адреса магазину на Позняках
- [ ] Ціни на кульки, доплати та готові композиції
- [ ] Вартість доставки по районах і поріг безкоштовної доставки
- [ ] Скільки тримаються кульки з Hi-Float (зараз — загальна інформація)
- [ ] Які послуги фотозон є насправді (монтаж, неон, оренда стійок) і ціни «від»
- [ ] Реальні фото товарів (або залишаємо ілюстрації на старті)
- [ ] Чи потрібна онлайн-оплата карткою, чи лишаємо оплату на рахунок ФОП

## Що підключити перед запуском

1. **Прийом замовлень.** Зараз замовлення зберігається лише в браузері покупця, а на екрані підтвердження є кнопка «Надіслати в Direct» з готовим текстом. Для запуску потрібно надсилати замовлення менеджеру: Telegram-бот, email чи CRM (місце позначене `ЗАМІНИТИ` в `assets/js/checkout.js`). Те саме для заявок на фотозону (`assets/js/product.js`).
2. **Онлайн-оплата** (за потреби): LiqPay, WayForPay чи Monobank Acquiring.
3. **Домен і хостинг.** Сайт статичний — підійде GitHub Pages, Netlify, Vercel чи звичайний хостинг.
4. **Аналітика** (Google Analytics / Meta Pixel), якщо потрібна реклама.
5. **Політика конфіденційності й публічна оферта** — для форми замовлення.

## Як переглянути

Сайт не потребує збирання — це звичайні HTML, CSS і JavaScript.

- **Локально:** запустіть будь-який статичний сервер у папці проєкту, наприклад `npx serve .` або `python -m http.server`, і відкрийте `http://localhost:3000` (або порт, який покаже сервер).
- **GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → гілка `main`, папка `/ (root)`. Через хвилину сайт буде за адресою `https://<користувач>.github.io/mi.ballloons/`.
